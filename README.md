# Overview

As a software engineer, I am continuously building foundational skills and exploring new tools to expand my technical toolkit. 

This is a simple Python command-line script that outputs a standard greeting to the console. It uses basic Python syntax and requires no external libraries, making it instantly executable in any standard Python environment.

My purpose for creating this software was to practice the fundamentals of Python development. Specific learning goals included:
* **Reviewing Core Syntax:** Reinforcing how basic Python scripts are written and executed.
* **Understanding Execution Flows:** Practicing how the Python interpreter reads code and handles standard terminal output.
* **Building a Foundation:** Establishing a clean, simple baseline to use as a starting point for more complex automation and scripting projects.


# Development Environment

* **Tools Used:** Visual Studio Code / Command Line Terminal
* **Programming Language:** Python 3
